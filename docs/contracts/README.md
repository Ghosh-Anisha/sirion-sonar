# Sample contracts for the Sirion Sonar prototype

13 adapted contracts (12 contracts plus the Orbis amendment). All parties are fictional. Each file has a PROTOTYPE NOTES block with the facts the prototype should extract and the label it should carry (Confirmed, Derived, Bounded or Unknown). The notes are not part of the contract text.

Wording is rewritten, not copied. The clause patterns follow the kinds of agreements found in the Law Insider sample library.
